# Lumière — Landing de Restaurante

Landing page demo para un restaurante de autor, con menú digital y reservas online.

## Qué resuelve

Muestra el menú del restaurante y permite recibir reservas directamente desde el sitio.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (reservas)

## Estado

Demo de portafolio.
